# Lakberendezési látványtervek

Az előtér, nappali, konyha és hálószoba fotói és berendezési koncepciói.

- **Eredeti fotók:** a projekt gyökerében, változatlanul.
- **Látványtervek:** az [`output`](output/README.md) alatt helyiségenként, azon belül leíró nevű változatmappákban.
- **Promptok és ellenőrzési megjegyzések:** [`output/dokumentacio`](output/dokumentacio/).
- **Áthelyezési jegyzék:** [`output/athelyezesi-jegyzek.json`](output/athelyezesi-jegyzek.json), fájlonként SHA-256 ellenőrzőösszeggel.

Minden változatot megőriztünk, kép nem lett törölve. A korábbi promptokban szereplő régi fájlutak helyett az output indexe mutatja az aktuális helyeket.

## Legutóbb kidolgozott változatok

| Helyiség | Változat |
|---|---|
| Előtér | [D-E5 – étkező, két antik fotel és konyhaelválasztó](output/eloter/D-E5-etkezo-ket-antik-fotellel/) |
| Nappali | [R1 – teljes helycsere](output/nappali/R1-teljes-helycsere-kis-komoddal/), [R2 – megosztott könyvtár](output/nappali/R2-megosztott-konyvtar-kis-komoddal/) |
| Konyha | [K12 – krém bútor, tölgy munkapult, eredeti csempe](output/konyha/K12-krem-butor-tolgy-pult-eredeti-csempe/) |
| Hálószoba | [H2C – cappuccino ágyfal](output/haloszoba/H2C-cappuccino-agyfal/), [H2T – pasztell türkiz ágyfal](output/haloszoba/H2T-pasztell-turkiz-agyfal/) |

A képek a beépített képgenerátorral készült hangulati koncepciók, nem méretarányos kivitelezési tervek. A pontos elférést helyszíni méréssel kell ellenőrizni; a képek között kisebb bútorarány- és részleteltérések maradhatnak.
